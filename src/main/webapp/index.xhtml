Person 1 Module: User Management & Skill Matching

Learn Together. Teach Each Other.

SkillSwap is a campus-exclusive platform where students list the skills they can teach, discover peers wanting to learn, and trade knowledge directly through smart skill matching!

Person 1 Feature Modules

👤

1. User Management

Student registration with USN, secure login/logout session handling, and customizable student profile with bio and department.

🎯

2. Skill Management

Manage skills you can teach (Offered) and skills you want to learn (Wanted), along with proficiency levels (Beginner, Intermediate, Expert).

🔄

3. Search & Reverse Match

Find mentors teaching Java or Python. Use Reverse Match to find peers wanting what you teach, with automated Skill Compatibility % calculation!
